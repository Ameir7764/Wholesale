## 4. SMART NETWORK STORE SYSTEM
----------------------------------------------------

Each WiFi network is a digital store.

When a user connects to a WiFi network:

STEP FLOW:
1. Detect network (SSID + BSSID mapping via captive portal system)
2. Check if network is registered in system database
3. If registered:
   - Automatically redirect user to that network's store page
   - Show packages, pricing, and purchase options
4. If NOT registered:
   - Show message: "This network is not registered"
   - Suggest nearby registered networks

IMPORTANT:
- Must use legal captive portal detection methods
- Must comply with OS restrictions
